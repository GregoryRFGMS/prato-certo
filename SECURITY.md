# Segurança

Este projeto é um MVP em desenvolvimento e ainda não foi validado para receber clientes reais.

Não coloque credenciais, dados de usuários ou exemplos de exploração contendo informações privadas em issues. Para informar uma vulnerabilidade, entre em contato diretamente com o proprietário do repositório por um canal privado já conhecido. Um canal público específico ainda não foi definido.

Antes de disponibilizar contas reais, validar dependências, migrations, cookies, origem das requisições, recuperação de senha, limites de tentativas, autorização por estabelecimento, backups e retenção. O status detalhado está no README e no roadmap.
